# 案内役（主人公）の人物設定

- 作成：2026-10-19（依頼02）
- 位置づけ：**架空の人物**。史実の人物ではない。画面・「この作品について」で「案内役は架空の人物です」と明示する
- 旅人の役は利用者本人。案内役は「一緒に歩いて、話をつなぐ人」

---

## 1. 名前

| 候補 | 表記 | 由来・ねらい | 気になる点 |
|---|---|---|---|
| **しおり（推し）** | しおり（漢字は「栞」を設定上の由来として持つが、画面ではひらがな） | 本の栞＝「どこまで読んだか」の印。続きを聴く・図鑑に記録する、というアプリの動きそのものと結びつく。俳諧の「しをり」（余韻・情の細やかさ）にも通じる。2〜3音で読み間違いがない | 一般的な名前・普通名詞なので、他の作品の登場人物とたまたま重なることはある（特定の作品を寄せる意図はない）。歴史上の著名な人物で「しおり」はユースの知る範囲では思い当たらないが、網羅的な確認はしていない＝**未確認** |
| ことは | ことは（言葉／言の葉） | 物語を言葉で手渡す役。響きがやわらかい | 「ことは」は「言葉」と同音で、ナレーション中に「ことはが…」と名乗ると聞き取りで混ざる恐れ |
| ちとせ | ちとせ（千歳） | 千年の時を案内する | 地名（北海道千歳市）・人名として多い。「千年」の含みが神秘めかしに寄りやすい |

**推し＝しおり**。理由：①アプリの「続き」「記録」の仕組みと名前が一致し、説明がいらない ②音声で聞いて一度で分かる ③神秘的でも時代的でもない（どの時代の物語にも浮かない）。

- 商標・既存キャラとの重なりは**未確認**（J-PlatPat 等で調べていない）。公開前にユースが確かめること

## 2. 立場（何者で、なぜ案内するのか）

> 各地に残る話を聞き集めて、旅の記録帳に書き留めている**記録係**。ひとりで集めた話を、その場所を歩く人と一緒に聴き直すために案内している。

- 神秘めかさない：時を越える力・精霊・使命などの設定は持たせない。「話を集めて、書き留めて、手渡す人」にとどめる
- 史実の人物と会話する場面は「記録帳に残された言葉を読み上げる／物語の語り手として場面をつなぐ」という建て付けにし、しおりが過去に行ったことにはしない（史実と創作をまぎれさせないため）

## 3. 話し方

| 項目 | 決め |
|---|---|
| 一人称 | 「わたし」 |
| 利用者への呼びかけ | 「あなた」。多用しない（1話に2〜3回まで）。名前を入力させる仕組みは今回作らない |
| 語尾 | です・ます を基本に、地の語りは「〜でした」「〜といいます」「〜のようです」。親しさは語尾でなく間と言葉選びで出す |
| 口癖（控えめ） | 「少し、立ち止まってみましょうか」（場面の切り替えにだけ使う。1話に1回まで） |
| 史実の言い方 | 確かなことは言い切る。史料で分からないことは「〜と伝わっています」「史料には残っていません」と分けて言う |
| 声 | 落ち着いた女性の語り。20代後半〜30代の印象。速すぎず、語尾を上げすぎない |

例（文体の見本・台本ではない）：
> 北山の池のほとりに、金色の楼閣が建っています。ここを建てた人は、どんな景色を見ていたのでしょう。少し、立ち止まってみましょうか。

### してはいけない話し方
- **説教**：「〜を学ばなければなりません」「〜を忘れてはいけません」など、利用者に教訓を押しつける
- **クイズ攻め**：「さて、ここで問題です」を繰り返す。問いは聴き終わりの**1行だけ**（要件6）。答えを迫らない
- **大げさな驚き**：「なんと！」「すごいですね！」「信じられません！」。驚きは中身（意外な事実）で出し、声と言葉は落ち着いたまま
- 煽り：「今聴かないと」「あと少しで○○達成」など期限・取り逃し・連続記録を言わない（共通の守る線3）
- 史実の人物を茶化す・見下す。開基・開山など寺がまつる人物はとくに丁寧に
- 創作を史実のように言う（「〜と言ったに違いありません」等）

## 4. 報酬設計との関係

設計の正本＝`design-chousa-2026-10-19.md` の「報酬設計」。しおりは**関係性**（自己決定理論の関係性）と**有能感を言葉で返す**役を担い、**ピーク・エンド**の「エンド」を受け持つ。

- 利用者の発見を言葉で返す：「何を知ったか」を具体的に一つ言い返す。点数・ランク・称賛の連呼はしない
- 自律を邪魔しない：次の物語は**提案だけ**。自動再生しない・急かさない
- 驚きの演出を積み増さない：驚きは物語の中身に任せ、しおりは受け止める側
- 歩いたこと（歩数）を褒めすぎない：歩数は手段。「歩いた量」より「聴いた中身」に触れる

### 聴き終わりの一言の型（5つ）

型の部品＝【知ったこと（具体）】【場所や人物とのつながり】【余韻・次は提案のみ】。1〜2文・15秒以内。

1. **持ち帰りの一つ型**：「今日いちばん心に残るのは、【知ったこと】かもしれませんね。」
   - 例：「今日いちばん心に残るのは、金閣が一度焼けて、建て直されたということかもしれませんね。」
2. **景色の見え方が変わる型**：「次にこの【場所】を見るときは、【知ったこと】を思い出すと、少し違って見えるはずです。」
   - ※「はずです」は台詞の言い回しとして許容（事実の報告ではない）
3. **人物の気持ちに寄せる型**：「【人物】が【したこと】の理由を、あなたはどう感じましたか。答えは急がなくていいです。」
   - 問い1行（要件6）と重ならないよう、問いが別にある回では使わない
4. **記録帳に書き留める型**：「この話は、わたしの記録帳にも書いておきます。【知ったこと】、と。」
   - 図鑑カードが記録される瞬間（報酬の瞬間「聴き終えた」）と合わせる
5. **つながりの予告型（提案のみ）**：「【人物／時代】の話は、別の場所にも残っています。歩きたくなったときに、また。」
   - 次を押しつけない。具体名を出すのは実在する次の物語があるときだけ（「準備中」を並べない方針・要件2）

## 5. 見た目の設計（絵のプロンプトは prompts.md）

| 項目 | 決め | 理由 |
|---|---|---|
| 年齢・性別の印象 | 20代後半〜30代の女性。顔立ちは落ち着いて素直、華美にしない。化粧感は薄く | 落ち着いた女性の語りと合わせる。年齢を強く限定しすぎない |
| 顔立ち | 卵形の輪郭・まっすぐ気味の眉・目は写実寄りの大きさ・口は小さめ。表情は眉と口元で控えめに | 絵柄の指定どおり。表情差分が眉と口元で作れる |
| 髪型 | 黒〜こげ茶の髪を、首の後ろで低くひとつに結ぶ（布の結び紐）。前髪は分けて額を少し見せる | 歩く人の実用的な髪。特定の時代の髪型（日本髪・現代の流行）に寄せない |
| 服 | 藍の短い羽織風の上着（腰下丈・前は紐で留める）／生成り色の立ち襟気味の内着（衿元に少し打ち合わせ＝和の要素）／苔色の細めのワイドパンツ／歩きやすい無地の靴 | 全時代になじむ旅装。和の要素は衿・羽織の形・紐だけにして、現代の人にも違和感がない程度に抑える |
| 持ち物 | **旅の記録帳**：手のひらより少し大きい、表紙が藍の和綴じ風の帳面。朱の栞紐が1本垂れる | 名前（しおり）・図鑑カード（記録されました）とつながる小物 |
| 色 | 藍 #1E3A5F（上着）・苔 #4F6B42（ズボン）・朱 #A8432F（栞紐と小さな差し色のみ）＋生成り（地色 #FAF6EE 寄り） | 案Aの3色。朱は面積を小さく（主張しすぎない・画面の朱ボタンとぶつけない） |
| 避けるもの | 神秘的な装飾（光・紋様・宝玉）／特定時代の装束（十二単・袴・軍服・洋装ドレス）／家紋・文字の入った意匠 | 架空と分かること・全時代を案内することのため |

### 4案の振れ幅（prompts.md と対応）
- 案1：上記の基本形（羽織風の短い上着＋紐留め）
- 案2：上着をやや長め（膝上丈）の旅用コートにし、肩掛けの布かばん
- 案3：上着は基本形、髪を首の後ろでゆるいお団子に、衿元を少し高く
- 案4：上着を前合わせのベスト風にし、内着の袖を見せる（より軽装）
